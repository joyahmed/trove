# Trove 0.1.0 (DRAFT)

The first public version of Trove: a fast file explorer with real tabs, one look on Windows, Mac and Ubuntu.

## New

- You can open many folders in tabs.
- You can press Ctrl K (⌘K on a Mac) to find anything, and Trove answers from its own list of file names first.
- A search index (on by default, off in Settings) finds files by name at once. On Windows it covers your fixed drives, on a Mac your home folder, on Ubuntu your home folder live and the rest of the disk every 30 minutes. It skips build and cache folders, finds close matches when your spelling is off, and a "Forget" button wipes it.
- You can use Spotlight, a small window opened by a shortcut you choose. It finds files and apps, does sums, and searches the web with the engine you pick.
- You can see each folder's size in the list. It is counted in the background.
- You can view files as cards grouped by date, as a list, or as a details table. A preview pane shows the file and its facts on wide screens.
- You can open a file with another app from the right-click menu ("Open with").
- You can open zip, 7z and tar files like folders, extract them, and make new ones. RAR is not supported yet. A password-protected 7z tells you so.
- You can see your installed apps in an Applications place and uninstall one from there (Mac: moves it to the Trash; Windows: runs its uninstaller; Ubuntu: hands it to apt, Snap or Flatpak).
- You can choose how Trove feels with "I'm coming from" in Settings, so names, keys and bin words match what you are used to.
- You can snap one Trove window to a half, or arrange all windows stacked, side by side or cascaded. Right-click the title bar for the window menu.
- You can drag files in and out of the window, and copy, cut and paste between Trove windows.
- You can see which program has a file open when Delete or Move fails, then Retry or End task.
- You can pin any folder to the sidebar, and unpin it again.
- You can pick System, Light or Dark in Settings, and an accent colour.
- You can use the mouse side buttons for Back and Forward.
- Windows and Ubuntu: Trove can be your default file manager.
- You can have Trove start at login (Settings, Behaviour).
- Mac only: Finder keys work in the list (⌘O, ⌘↓, ⌥⌘⌫), ⌘[ ⌘] ⌘↑ move around, and picture, video and app thumbnails come from QuickLook.
- Mac only: ⌘Z puts back an item Trove sent to the Trash.
- Linux only: the terminal pane starts your own shell, and "Keep running" shows or hides the tray icon.
- On Linux, videos over 512 MB open in your video player.

## Better

- Trove looks the same on every system: bundled fonts and one blue accent.
- Copies and moves carry on past a file they cannot read, then list what did not arrive and offer "Retry failed".
- Menus work with the arrow keys, and each Esc closes one layer.
- Trove follows reduced motion and Windows high-contrast themes.
- Local drives show at once, even while a dead network drive is still answering.

## Fixed

- Delete no longer says nothing when the file stayed in its folder.
- Right-clicking a file inside a zip no longer crashes Trove on a Mac.
- Zip files with accented or non-English names keep their names.
- Alt+Space no longer hangs the page on Windows, and Alt+F4 on Spotlight no longer stops the shortcut working.
- After renaming or closing a confirm box, the keyboard goes back to the file list.
- Ctrl+Z undoes typing in the rename box and address bar on Linux.
- The release log no longer writes file paths.

## Good to know

- No automatic updates yet. To update, download the new version and install it over the old one.
- The downloads are not signed by a known publisher yet, so your system will warn you the first time.
- On Windows the index also reads the drive's change log, so it is current the moment Trove opens. On Mac and Ubuntu it walks the folders again when Trove starts.
- Mac: Trove asks to talk to Finder so the Trash and Put Back work.

## Downloads

- Windows: Trove setup .exe
- Mac: Trove .dmg
- Ubuntu: Trove .deb, or the AppImage

If your computer warns that the app is from an unknown publisher, here is how to open it anyway:

- Windows: click "More info", then "Run anyway".
- Mac: open System Settings, then Privacy & Security, then "Open Anyway" once.
- Ubuntu: install the .deb, or make the AppImage executable and run it.

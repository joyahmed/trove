Symbols Nerd Font Mono (symbols-nerd-font-mono.woff2)

Source: Nerd Fonts v3.5.1 release asset NerdFontsSymbolsOnly.zip
  https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1
File: SymbolsNerdFontMono-Regular.ttf, subset and converted to WOFF2 with fontTools 4.60.2.

Removed: the Font Logos set (U+F300-F385, 134 glyphs named linux-*). Upstream lists its license
as "unlicensed", so Trove does not ship it; those code points fall back to other fonts. No
other glyph was removed or changed (FontForge's private PfEd table was dropped by the subsetter).

The Nerd Fonts project is under the MIT License below. The glyphs come from the upstream icon
sets listed after it, each under its own license; this file is the attribution the CC BY 4.0
sets ask for.
